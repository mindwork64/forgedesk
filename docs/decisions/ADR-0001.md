# ADR-0001 — Desktop stack and core boundary

**Date:** 2026-11-15  
**Status:** accepted  
**Stage:** 0

## Context

ForgeDesk is a single-user, local-first desktop application for Windows and
Linux. It needs a Rust core, SQLite storage, deep GitHub integration with strict
API budgeting and a dense keyboard-driven UI. There is no existing repository;
the project starts empty. The environment has no backend infrastructure and the
product explicitly forbids one.

## Decision

1. **Tauri 2 + Rust stable + Vue 3 + TypeScript + Vite + SQLite.**
   - The Tauri webview is UI only. All persistence, permissions, provider calls
     and Git execution live in Rust.
   - SQLite is accessed only by Rust through `rusqlite` (`bundled` feature), never
     by the frontend and not through the Tauri SQL plugin.
2. **Cargo workspace with an independently testable core crate.**
   - `crates/forgedesk-core` owns domain, storage, backups and (later) providers,
     sync, API budget, Git and automation.
   - `src-tauri` owns the Tauri builder, window lifecycle, typed commands and
     error mapping. It depends on the core; the core never depends on Tauri.
   - `default-members = ["crates/forgedesk-core"]` so `cargo test` at the root
     verifies domain/storage without desktop webview libraries. CI additionally
     builds the Tauri shell on Windows and Linux.
3. **Single guarded SQLite connection, WAL, serialized writes.**
   - `Database` holds `Mutex<Option<Connection>>`; all access is serialized and
     transactions are explicit. This matches the single-user constraint and
     avoids concurrent-writer complexity. The connection can be closed/reopened
     for restore.
4. **Append-only migrations keyed by `PRAGMA user_version`.**
   - No migration library; the runner is ~80 lines and fully tested. Each
     migration runs in a transaction and records itself in `schema_migration`.
   - A newer schema is refused instead of downgraded or reset.
5. **Typed IPC only.**
   - Commands return DTOs and `CommandError { code, message, field?, detail? }`.
     There is no generic SQL/shell/HTTP command. Tauri capabilities are minimal.
6. **Backups use `VACUUM INTO` + manifest + SHA-256.**
   - Snapshot, checksum and integrity checks are testable in the core. Restore
     validates first, creates a safety snapshot, replaces the closed database and
     reopens it; a failed reopen rolls back.
7. **One bootstrap payload.**
   - `bootstrap` returns app version, schema version, paths, workspace, settings,
     backup list and startup warning in one command to avoid a waterfall of IPC.
8. **Frontend stack:** Vue Router + Pinia + `vue-i18n` + Lucide (`@lucide/vue`),
   no UI kit. Design tokens are CSS custom properties. Everything visible follows
   `06_UI_UX_SPEC.md`; the UI Gate 0 screenshots are the acceptance artifact.

## Consequences

- Core logic is testable without webview system packages, which matters on Linux
  CI and in constrained development environments.
- The Tauri shell is a thin adapter and can be rebuilt with future Tauri 2
  versions without touching domain/storage.
- One connection serializes reads and writes. This is intentional for v1; if
  profiling shows long reads blocking writes, read-only connections can be added
  behind the existing `Database` API.
- Restoring a backup closes the connection briefly, so the UI must treat restore
  as a blocking maintenance action with confirmation.
- Bundled SQLite increases compile time but removes a runtime dependency on the
  host SQLite version (FTS5 availability is consistent).

## Rejected alternatives

- **Separate HTTP backend / Electron / embedded Chromium** — forbidden by the
  product and adds unnecessary attack surface and infrastructure.
- **`sqlx` + async pool** — unnecessary for a single writer; async brings runtime
  and compile-time cost without a concurrency requirement yet.
- **Tauri SQL plugin** — would expose SQL semantics toward the webview; the
  specification requires DB access behind Rust repositories.
- **ORM / query builder** — small schema and explicit SQL keep migrations and
  query plans auditable.
- **Generic UI kit theme** — forbidden; ForgeDesk has its own token contract.
- **Two top-level Rust crates without a workspace** — duplicated dependency
  resolution and no shared lockfile.
